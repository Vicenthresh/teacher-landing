# Session: Draft the home page with placeholder content that sells "Miss Javi" (hero, contact, CV, projects, blog) on a switchable 90s → XP → Aero desktop
Tier: long   Branch: session/draft-content   Test: pnpm build
Out of scope: /en/ pages; real name, photos, prices, phone number, email or CV file; blog post pages and content collections (Phase 2); deploy; cursor trails or any new JS effect beyond the switcher; new sound effects; y2k as a page theme (it stays a styleguide skin and accent); wallpaper or effect images (CSS gradients + inline SVG only); docs/phase-0.md and the README screenshots.

Ground rules for every item: copy only in `src/data/*.json`; default skin is `aero` and the page renders correctly with JS off; `prefers-reduced-motion: reduce` stops every animation; animate only `transform`/`opacity`; at most one `backdrop-filter` panel per viewport, with an `@supports` fallback; a task that needs a text/background pair not already audited in F1 stops and reports it instead of adding colours.
